How far to trust it

Setup is validated, the car isn'tThe same solver settings matched the Ahmed body within its measured Cd band. There is no published Roadster data, so treat these as a well-set-up estimate, not a measurement.
Geometry is an estimateBuilt from press photos: proportions are right, details (underbody, cooling inlets, mirrors, panel gaps) are simplified. Real cars add roughly 0.02-0.05 to Cd for cooling flow and detail.
Steady RANSThe wake and tyre flow are unsteady. Averaging iterations 1600-2500 smooths that; a transient run would firm up lift more than drag. Front tyre-to-well gap is ~2.5 cells across.
